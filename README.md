# PIM-3-Import-Cell

O trabalho aborda um cenário fictício de um sistema para venda de smartphones usando a linguagem C#, modelagem de banco de dados NoSQL.

C# (lê-se "C Sharp") é uma linguagem de programação moderna, orientada a objetos e fortemente tipada, desenvolvida pela Microsoft como parte da plataforma .NET. Criada para ser flexível e segura, é amplamente utilizada no desenvolvimento de aplicações desktop, web, serviços em nuvem e, notavelmente, jogos com a engine Unity.

Bancos de dados NoSQL ("Not Only SQL" ou "não apenas SQL") são sistemas não relacionais projetados para alta escalabilidade, flexibilidade e armazenamento de grandes volumes de dados não estruturados. Diferente das tabelas fixas do SQL, usam modelos como documentos, grafos, chave-valor ou colunar, ideais para tempo real, Big Data e desenvolvimento ágil.
